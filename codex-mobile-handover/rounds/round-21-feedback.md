1. **点击停止后回填输入框了，但消息列表还存在被编辑（被中断）的消息**：中断后服务端已整体移除该 turn，但本地 `persistedMessagesByThreadId` 仍有该 turn 消息，`loadMessages` 的 `preserveMissing` 合并会保留它们。修复：`interruptSelectedThreadTurn` 判定「未提交 turn」成立后，同时从本地移除该 turn 的全部持久化消息（按 turnId）+ 该 turn 的思考存档（`clearCompletedTurnLiveState` 刚把 thinking 存进 `persistedReasoning`，不清理会残留无轮次的孤儿思考块），再设置回填载荷。新增 2 个单测锁定（未提交 turn 移除消息/思考 + 回填载荷；有 agent 输出的 turn 不受影响）。
2. **thinking 宽度与其他消息不一致**：两处根因——①live overlay 的 `.live-overlay-inline` 用聊天列宽（`--chat-column-max` 45rem），普通消息是卡片宽（`--chat-card-max` 76ch），实时 thinking 比普通消息宽一大截；改为卡片宽。②reasoning 块进 Process Fold 后撑满折叠容器全宽；随第 8 条修复为平铺后宽度自然与消息一致。
3. **计划 popover 内容重排版，对齐审核/询问面板样式**：`ThreadComposer.vue` 计划展开 popover 步骤行卡片化（`rounded-xl border bg-white px-3 py-2`，暗色 `border-zinc-700 bg-zinc-800`）、Summary 卡片化（`rounded-xl bg-zinc-100`，暗色 `bg-zinc-800/70`）、Implement 按钮胶囊化（`rounded-full h-10 px-4`），popover 内边距加大（`p-3.5`）；暗色覆盖同步 `style.css`。
4. **消息中的 thinking 需要居左显示**：reasoning 块（平铺）与普通消息同为 `x=411` 左对齐（Playwright 断言 shared x）；live overlay 左对齐由 `message-stack items-start` 保证。
5. **（问题）thinking 完成后 thinking 块就消失了吗**：结论——live 实时 thinking（Thinking 标题 + 流式文本）在 agent 开始输出正文或 turn 完成时消失是预期（它只是运行期间的实时预览）；消息列表中的存档「Thinking process」折叠块（`rememberPersistedReasoning` → localStorage `codex-web-local.thread-reasoning.v1`）是持久记录，刷新后仍保留。此前用户看不到块的根因是第 8 条（被 Process Fold 折叠），修复后稳定可见；Playwright 注入 localStorage 存档断言块数 = 3 mock + 1 存档。
6. **user 发送的消息，下方的编辑消息字是白的无法看到**：根因是工具栏悬停显隐失效——`MessageToolbar.vue` scoped 内 `:global(.message-row:hover) .message-toolbar { @apply opacity-100 }` 被 Vue scoped + Tailwind 编译成 `.message-row:hover { opacity: 1 }`（声明挂到 `:global` 部分的选择器上，作用在行上而非工具栏），工具栏永远 `opacity: 0.01`（文字以 1% 透明度渲染，看起来像白色浅痕）。修复：该规则移到全局 `style.css`（`.message-row:hover .message-toolbar { opacity: 1 }`），Playwright 实测 hover 后 `opacity: 1`。
7. **user 消息下的编辑改为回退**：`MessageToolbar.vue` 编辑按钮改为回退按钮（`.message-rollback-button`，图标 `IconTablerArrowBackUp`，文案「回退/Rollback」，暗色覆盖 `style.css` 已有）；确认对话框标题「Edit this message?」→「Rollback this turn?」（中文「回退到该轮？」），描述不变（回退到该轮、后续回复被移除）。
8. **消息列表的思考过程块怎么时有时没有**：根因——`buildProcessFolds` 把同轮 reasoning 与命令/工具一起折叠（≥2 条时），思考块只在展开折叠条后可见。修复：`isFoldableProcessMessage` 排除 reasoning（仅命令/工具折叠），思考块始终平铺；折叠条文案不再含思考计数（既有 `thoughtCount` 分支保留无害）；`conversationFolds.test.ts` 两处断言同步更新。
