## 步骤与预期

1. **楼层形态（暗色）**：打开采样线程，找任一代码块。预期：14px 圆角、`--s2` 表面、`--line-1` 发丝边；bar（`--s1` 底 + 发丝下边）在代码区之上；语言标签（如 `TEXT`）大写等宽 11px、靠左；代码区文字 `--ink-2`、等宽 13px。楼层不再永远深底——亮色下应为白/浅表面。
2. **楼层形态（亮色）**：切亮色主题重复步骤 1。预期：bar 比代码区略深一档（`--s1` vs `--s2`），楼层边框可见。
3. **复制（模板路径）**：点击代码块 bar 右侧「复制」。预期：控件文字变「已复制」并转绿色（`--ok`）；粘贴验证剪贴板内容与代码逐字一致；约 1.6s 后控件文字还原为「复制」。
4. **复制（v-html 路径）**：展开一条含代码块的思考/推理块（ReasoningBlock），重复步骤 3。预期：行为与模板路径完全一致（同一份委托）。
5. **无语言的代码块**：找一个无语言标注的代码块（如有）。预期：bar 只显示右侧「复制」，不出现空的语言槽。
6. **键盘**：Tab 聚焦到「复制」控件后按 Enter。预期：触发复制，行为与点击一致。
7. **静置对照**：不滚动、不交互，刷新页面后观察 10s。预期：代码块外观稳定，无复制反馈残留。
